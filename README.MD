# Agentic AI
Repository containing labs from Agentic AI course
## Repository structure

|Files|Description|
|--------------------------------|-----------|
|[LAB 01 Prompt Engineering Lab](Lab1-PromptIngineering/) | Prompt engineering (tokenisation, ollama, Groq, OpenAI, JSON, images)|
|[LAB 02 Agents with LangChain](Lab2-AgentsLangchain/) | Agents with langchain (memory, tools, web search) Final project: Personal chef|
|[LAB 03 RAG](Lab3-RAG/)|RAG on pdf using huggingface and agent SQL using Chinnok DB|
|[LAB 04 MCP](Lab4-MCP//)|Model Context Protocol : stdio, HTTP streaming|
|[LAB 05 LangGraph Studio](Lab5-LangraphStudio/)|Multi agents + LangGraph for visualisation|


## General requirements
        Python: 3.12+
        uv: Package manager
        Ollama: Tool to run, manage, and customize Large Language Models (LLMs) directly on your own computer

## How to use
Every lab file contain different scripts with their own virtual environnement and execution steps

## Notes
* Some of the labs require an active API key.
* Each lab contains a description of `.env` file structure
